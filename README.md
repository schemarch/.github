# ScheMarch

ScheMarch is a connected Postgres backend with authentication, storage, realtime, APIs, and server-side functions.

Build applications around a Postgres database, manage project data through a protected dashboard, and connect clients through REST APIs and the JavaScript SDK.

## Access and ecosystem

Project access is provided by an administrator. Public signup and automatic project provisioning are not currently available.

The ScheMarch organization hosts the platform and supporting clients, SDKs, and development tooling. Source repositories currently require maintainer permission; see [source access and licensing](https://schemarch.com/about) for details.

[Browse publicly available repositories](https://github.com/orgs/schemarch/repositories)
